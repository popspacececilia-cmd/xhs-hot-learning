# 素材底稿字段与证据来源

灵造是平台素材底版的主要采集工具，但底稿字段必须根据实际证据来源标注，不把文本推断写成真实画面事实。

## 文字层

| 字段 | 首选来源 | 处理规则 |
| --- | --- | --- |
| 标题结构、标题钩子 | 灵造标题 | 标题原文属于事实，结构与钩子属于分析 |
| 关键词和情绪词 | 标题、正文、逐字稿 | 保留出现位置和叙事功能 |
| 正文结构 | 灵造正文 | 正文与视频逐字稿分开 |
| 开头承诺 | 逐字稿或原视频 | 只有逐字稿时注明文本来源 |
| 信息密度 | 正文、逐字稿、本地视频 | 无时间轴时只判断文本密度，不声称精确节奏 |
| 叙事路径 | 正文与逐字稿 | 属于分析判断 |
| 行动引导、语言风格 | 正文、逐字稿 | 有真实原文才记录 |
| 评论互动话术 | 正文引导、公开评论、作者回复 | 没有作者回复时不推断真实互动方式 |

## 图片层

| 字段 | 首选来源 | 处理规则 |
| --- | --- | --- |
| 首图/封面、封面 OCR | 灵造封面或用户截图 | 保存原图和可见文字 |
| 构图、人物、产品、环境、色彩 | 实际图片 | 只能基于可见画面 |
| 每张图片功能、图片顺序 | 灵造图片列表或用户图片 | 只有封面时明确无法分析多图叙事 |
| 图文对应 | 图片与正文 | 属于关系分析 |

## 视频层

| 字段 | 首选来源 | 处理规则 |
| --- | --- | --- |
| 平台时长、语音转写 | 灵造 | 可作为视频文本底版 |
| 前三秒真实画面、镜头分段、关键帧 | 本地视频 | 仅逐字稿时不能声称真实镜头验证 |
| 画面 OCR、字幕样式 | 本地视频关键帧 | 灵造只返回转写时标记缺失 |
| 音乐、环境声音、音效 | 本地视频音轨 | 无音轨分析时标记未获取 |
| 剪辑节奏、出镜方式、场景顺序 | 本地视频 | 逐字稿只能推断内容段落 |
| 结尾引导 | 逐字稿与原视频 | 区分口播引导和视觉引导 |

## 数据与评论层

| 字段 | 首选来源 | 处理规则 |
| --- | --- | --- |
| 点赞、收藏、评论、分享 | 灵造笔记详情 | 保留获取时间；缺失使用 null，不使用 0 |
| 比例与倾向 | 平台数据 | 只支持倾向，不证明因果 |
| 评论关注、疑问、反对、补充 | 灵造公开评论 | 说明排序和样本范围 |
| 资料、服务或购买意图 | 真实评论原文 | 没有原文时不推断 |
| 数据与结构关系 | 底稿和数据 | 必须保留替代解释 |

## 账号适配层

账号适配不由灵造单独决定。读取个人运营工作区中的账号定位、受众、语言、人设、阶段、制作能力、近期内容和已有规则，再判断可借鉴、不可照搬、原创迁移、冲突、选题和候选规则。
